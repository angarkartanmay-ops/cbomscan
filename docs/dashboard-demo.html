The problem

An ESP32 ships once and stays in the field for ten years.

Secure Boot, OTA updates and device certificates rest on RSA and elliptic curves. Shor's algorithm breaks both. Published estimates for breaking RSA-2048 fell from about 20 million qubits in 2019 to under one million in 2025.

2030NIST draft: deprecate
2035NIST draft: disallow

01 · Read the binary

Open the image. No source code needed.

cbomscan parses the compiled, stripped app image: its memory segments, the app descriptor and the Secure Boot V2 signature block.

  • DROM
  • IRAM
  • IROM
  • Signature block

02 · Match the maths

Every algorithm leaves a fingerprint.

S-boxes, round constants, OIDs, embedded public keys, algorithm names and accelerator registers. Each hit becomes evidence at an address, and the evidence adds up to one confidence score per algorithm.

  • Quantum-vulnerable
  • Weak today
  • Quantum-safe

03 · Plan the migration

Every finding comes with a replacement.

RSA and ECDSA signatures move to ML-DSA or LMS. Key agreement moves to ML-KEM. MD5, SHA-1 and 3DES are flagged as weak today. The report is a CycloneDX 1.6 Cryptography Bill of Materials.

  • ML-KEM · FIPS 203
  • ML-DSA · FIPS 204
  • LMS · SP 800-208
